# AgentRecBench 固定候选对照

复用本轮 Waterfall 冻结输入与官方短历史 300 题。仅新增 ClawRec 固定候选适配版与通用 Agent 固定候选版。两法读取相同的完整可见评论和历史物品详情、公开用户资料、任务字段及 20 个候选的原始顺序和公开文本。Waterfall 的实际运行工具只回查这批已有历史，没有新增外部数据。算法、原有格式校验和重试路径保持各自版本，调用次数另记。

先复用 Waterfall 原验收的六题。要求全部返回 20 项唯一合法排列，模型回执一致，原始请求与公开输入吻合。Amazon 和 Goodreads 四题合计每法至少命中一题，作为粗略的随机期望核对。Yelp 两题单报，检查无历史和有历史都能合法交付。小批数值只用于验收，未通过即停。通过后复用已验收结果，补齐每法 300 题。正式比较报告 300 题、各域和既有 i²Agent 共同适用 220 题。ClawRec 标为固定候选适配版，进入单独对照表。
