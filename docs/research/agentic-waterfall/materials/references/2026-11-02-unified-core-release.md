## 改了什么

1. 已获取的历史记忆证据可继续引用；仍拒绝凭空编造的依据。证据通道沿直接引用和历史回查传递，避免消融条件借记忆找回被移除的信息。
2. 非目标消融保留历史回查能力；回查继续过滤其他用户、其他策略和未来记录。未修复或重新认定旧结果有效。
3. 查询资料/评论的请求数量不再误占“新增候选数量”限制；实际新增候选与调用边界仍按原协议检查。
4. 后到的检索结果、补全已有 ID 的资料也会触发后续判断；保留已有的提前交付与并发获取能力。
5. 本地同步存储、默认私有配置路径、旧兼容入口保持可用；补齐遗漏的旧本地盲选 Waterfall 路由。
6. [当前中文系统提示词](2026-11-02-waterfall-prompt.md) 逐项说明输入、记忆、历史回查、获取和重排，并用通用例子说明任务切换与深度调整。说明使用中文，JSON 字段和动作名保留协议拼写；未新增成本优先限制或特定场景规则。
