# Agentic Waterfall 非训练方法：实验就绪记录（2026-10-29）

## 范围和结论

本次推进不包含 Waterfall 本身、真人内容评分、消融、模拟用户、盲选，也没有开始训练或正式效果实验。方法放在 `methods/agentic-waterfall/`，公共数据放在 `datasets/agentic-waterfall/`；现有产品实现未被替换。

**不能把全部方法和全部基准一概称为 ready。** AgentRecBench 的 RecAgent 三领域、MIND 的四个固定候选适配器已具备批量入口并完成真实模型样本验证；ClawRec-SimBench 的 ClawRec 与通用 Agent 已具备受限快照环境和连续事件入口，但这是与作者原始开放网页环境有差异的适配。KuaiRec、KuaiRand 的完整比较仍有下述限制。正式运行前需要按实际任务打开运行保护额度并确定成本；当前 API 与下载开关均关闭。

## SimBench 共同环境及信息边界

用户批准从公开来源自动准备首批内容。共112次查询，冻结1,109条去重内容：B站556、知乎279、YouTube274。210个事件的允许来源中至少有一个与快照相交，但小红书、淘宝、京东、百度等没有纳入；来源覆盖不等于内容主题覆盖或检索质量充分。快照在2026-10-29采集，而轨迹发生在2026年5–6月。执行时剔除发布时间未知或晚于事件的内容，但这无法证明当时网页文字与今天相同。因此这只能叫**事后收集、按发布时间过滤的受限共同快照**，不能冒充作者原始实时网络或全平台结果。

审计发现公开提取数据中的 `next_content_keys` 可能指向当前看不到的内容。已按作者现有可见内容规则过滤：210个事件共2,260个指向可见内容之外的引用被去除，并强制检查事件/步骤边界。修复前的 `*-dev-event{1,2}-20261029` 和对应合并池已列入 [`simbench/runs/invalidated-forward-references-20261029.json`](simbench/runs/invalidated-forward-references-20261029.json)，只保留审计，不得用于实验或评分。修复后四次真实调用链保存在 `*-boundary-event{1,2}-20261029`，状态按方法和用户隔离；只冻结推荐池，未计算效果。

## 还不能说 ready 的部分

- **KuaiRec**：ClawRec、通用 Agent、i²Agent 与固定检索均完成过真实单样本检查；ClawRec/通用 Agent/固定检索已补批量入口，三者的两用户真实执行和无标签导出已通过；全量执行、所有对照采用相同可评范围以及失败结果进入完整评分尚未完整验证。当前静态任务每位用户独立一期，不宣称已完成跨期连续状态实验。数据的观察掩码会暴露用户–物品是否有观察记录，必须所有方法一致使用并披露。
- **KuaiRand-1K**：用户已批准下载官方 3.22 GB 字幕并适配现有 36 条。36 条的最近64次公开历史已冻结，公开时间与候选约束检查通过；按用户决定，正式共同比较35条（开发21、测试14），另报1条 i²Agent 历史不足。共同样本目前只有基础资料版，字幕文件尚在下载；完成后必须验证官方 MD5、ID与时长，再补充文本并做真实模型检查，不能提前称为就绪。下载后会自动执行非训练的数据校验、批量预检以及用户授权的各方法单样本真实调用，状态见 `kuairand/caption-finalization-status.json` 和 `kuairand/caption-live-check-status.json`；仍须依据实际结果判定是否就绪。
- **Baseline666**：未找到可核实作者代码，已按用户决定移出当前实验。训练类方法及需要训练的 RecBot AIA 按用户要求不动。
- i²Agent 在 AgentRecBench 三领域已接入并各完成一个真实样本；100题中 Amazon 96、Yelp 32、Goodreads 92 条至少有两条可见评论，其余 4、68、8 条按用户决定标为不适用。Yelp/Goodreads 使用用户批准的官方文件顺序，不是时间排序；目标时间和评论严格先后仍不可核实。相同适用子集的评分入口为 `i2agent/score_agentrecbench.py`，与 RecAgent 全100题结果的分母必须分别说明。SimBench 固定检索已使用同一冻结快照与事件时间过滤建立1,109项索引、准备210事件批量入口，并在一事件真实推理后与 ClawRec、通用 Agent 合并冻结42条匿名内容；仍未运行该三方法池的裁判或全量评分。

## 复核与资源

此前40次、后续29次共享模型请求用于连接和边界检查，其中包含修复前作废的请求；没有基于这些结果声明方法效果。SimBench 的 Python 测试15项、Node 测试9项；RecAgent 测试13项、数据索引/下载测试9项，方法目录基础测试19项、KuaiRand 新增测试5项、固定检索测试10项，以及通用 Agent 与 ClawRec 的相关 Node 测试通过。测试无法证明完整数据集上的模型输出都合法。

正式 MIND 967题的一遍请求量预估为：ClawRec 1,934、i²Agent 4,835、MARS 最多6,163、RecBot 1,934；实际失败、调用数、token 与费用需要据运行收据另计。用户已决定不设各方法统一模型调用上限，而是报告真实调用与成本。当前方法目录的模型调用开关关闭，共享账本的余量会受其他任务并发影响；正式实验需要在运行时设置足够的操作保护额度，不会自动开始。

## 执行入口

以下路径均从工作区根目录运行。`<新输出目录>` 需要是不存在的路径；只准备清单时去掉 `--execute`。任务运行会产生真实 API 成本，须先为该次实际运行配置操作额度。失败、未完成和额度拦截须分别保留，不得把没开始的题当成模型预测。

- MIND 固定候选：`python3 methods/agentic-waterfall/batch_public.py --input methods/agentic-waterfall/protocols/mind-common-i2agent-967-20261029/inputs-eligible.jsonl --method clawrec --dataset mind --count 967 --output <新输出目录> --execute`。`--method` 也可选 `i2agent`、`mars`、`recbot`、`generic-agent`。
- AgentRecBench：`experiments/agentic-waterfall/agentrecbench/.venv/bin/python methods/agentic-waterfall/recagent/batch.py --domain yelp --index methods/agentic-waterfall/agentrecbench-data/index/yelp-short.sqlite --output <新输出目录> --execute`。其他领域将 `yelp` 同时替换为 `amazon` 或 `goodreads`。
- KuaiRec：`python3 methods/agentic-waterfall/kuairec_batch.py --input methods/agentic-waterfall/protocols/kuairec-public-20261029/kuairec-dev-public-20261029.jsonl --method clawrec --output <新输出目录> --execute`，方法可选 `generic-agent`；`--resume` 用于继续同一批次。`kuairec_predictions.py` 要求每个用户都有实际结果，并拒绝将额度不足或进程中断记为方法失败。现有导出器与 evaluator 仍需多用户真实评分核验。
- SimBench：`python3 methods/agentic-waterfall/simbench/batch.py --cases datasets/agentic-waterfall/clawrec-simbench/ClawRec-6eeb309c47430f91280e9845a98fb56a68dc0d90/clawrec-simbench/cases --snapshot methods/agentic-waterfall/simbench/snapshots/public-generic-with-dates-20261029 --method clawrec --output <新输出目录> --execute`，方法可选 `generic-agent`。跨方法评分应待各方法结果冻结后再使用上述评分工具；真实目标只供评测侧读取。

通用 Agent 的首次 MIND 两条测试中有一条漏排，已保留失败；加入一次有记录的格式纠错重试后，同一题返回完整26条。该次成功在首次排序即完成，重试分支通过合成测试；不能据此保证全量成功。KuaiRand 一条101候选真实检查也成功，后续带正式字幕的真实检查以状态文件为准。

2026-10-29 后续：用户批准对 Yelp 和 Goodreads 按官方文件顺序处理 i²Agent 历史；三领域各100题已形成输入预检，真实模型分别验证 Amazon 0、Yelp 6（含缺资料）及 Goodreads 0 均返回完整排列。真实 SimBench 单事件裁判与共享池指标流程已通，但只能作诊断。

AgentRecBench 的 i²Agent 批量入口示例：`python3 methods/agentic-waterfall/i2agent/agentrecbench_batch.py --domain yelp --index methods/agentic-waterfall/agentrecbench-data/index/yelp-short.sqlite --output <新输出目录> --execute`。准备阶段固定全部100条并标记不足两条历史者；评分时使用 `i2agent/score_agentrecbench.py --i2-batch <i2输出> --recagent-batch <recagent输出> --output <新评分目录>`，先固定结果再只对 i²Agent 适用任务读取标签并比较同题，另报不适用数量。不得把此共同子集的成绩与 RecAgent 全100题成绩当成相同分母。

SimBench 固定检索：先通过 `fixed-retrieval/simbench_catalog.py` 从冻结快照生成公开目录，用现有 `retrieval.py index` 建 BGE 索引，再用 `fixed-retrieval/simbench_batch.py` 按事件来源及时间过滤；已完成一事件真实本地推理，20条推荐均来自100条实际取得的候选。

MARS 连续状态补充：同一公开历史分三批做真实模型管线诊断，共4次请求；后两批均选择跳过更新，不能当作真实多会话或偏好更新效果证据。
