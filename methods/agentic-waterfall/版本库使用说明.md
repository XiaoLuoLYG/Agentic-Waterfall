# 版本库使用说明

本目录保存本研究的适配代码、测试、论文复现说明及实验边界。数据集、公开内容快照、模型权重、API 密钥、模型调用日志、输出、SQLite 索引和下载中间文件保留在本地，不作为代码提交；克隆代码并不自动具备完整实验数据或证明实验结果。

## 上游代码与依赖

- ClawRec 的固定 Skills 快照附带原 MIT 许可证与提交标识，见 `clawrec/source-snapshot/LICENSE` 和 `source-manifest.json`。
- iAgent 仓库未发现明确许可证，版本库不分发其源文件。需要使用时运行 `python3 methods/agentic-waterfall/i2agent/fetch_author.py`；它只获取固定提交的 `model.py`，校验 SHA-256，不覆盖已有不同内容。
- 官方 AgentRecBench/RecAgent 代码不随本目录打包。运行 `python3 methods/agentic-waterfall/agentrecbench-data/fetch_official.py` 获取固定提交的 MIT 源码；脚本校验归档哈希、检查归档路径和大小，不覆盖已有源码。`recagent_all_candidates.py` 是本研究的候选列表修复适配。
- 固定检索使用 `fixed-retrieval/requirements.txt` 中核验过的依赖版本，现成权重及其固定修订和校验值见 `fixed-retrieval/README.md`。下载或编码不是训练；权重和索引不会提交。

## 本地数据和模型调用

脚本使用工作区中的 `datasets/agentic-waterfall/` 和 `experiments/agentic-waterfall/` 本地数据目录，前者不在本提交内；可在新环境重新准备数据，或自行连接已存在的同结构数据目录。相关路径和各实验验证范围见 `实验就绪报告-20261029.md` 与 `实验限制与解读-20261029.md`。本地运行收据和人工核验记录同样不提交，报告中的本地记录路径只适用于原工作区。

默认禁止模型调用和训练。需要用户授权的试运行时，在本地把 `model-control/CONTROL.example.json` 复制为 `model-control/CONTROL.json` 并配置调用开关和操作额度；`experiments/agentic-waterfall/method-deployment` 指向此目录。模型客户端从本地配置或环境变量读取凭据，切勿提交配置文件和凭据。共享操作额度与论文中是否限制各方法调用数是两回事；具体记账、有效失败和未运行处理参见报告。

代码经过本地离线测试和部分真实小样本检查；完整批量、数据版权可重新分发性、外部 API 可用性及正式效果不由这次代码提交保证。
