# 方法继续部署计划

目标：在不训练和不修改原实验的前提下，把已授权方法推进到可运行、可审计的对照入口；实验效果与方法复现忠实度分别记录。

- RecBot：独立实现 Parser、动态偏好、Planner、过滤、语义匹配、衰减和聚合；由于没有训练过的 AIA 权重，以显式 `semantic-only` 模式运行并拒绝声称完整 RecBot。用 MIND 公开输入和人工构造多轮指令验证输入隔离、状态与排序。
- MARS：独立实现事件、偏好、画像三级记忆及 agentic 更新，采用论文参数，逐项调用模型评分；用 MIND 公开输入和多轮合成事件验证生命周期及候选约束。
- 推广已有方法的输入/批处理与跨轮入口，核查评分器、共同候选、方法独立状态和预算，不把单样本有效输出当成效果；仍需训练的对照仅准备入口、标出权重阻塞。
- 保持输出独立，模型调用记录共享账本；保存输入、提示、响应、状态与可复现命令。运行适当的单元、真实 API 和多样本接线检查；记录不可声称 ready 的条件。
