# Agentic Waterfall 实验限制与解读（2026-10-29）

本文是执行和解读边界，不是效果结论。代码、模型、数据和实际实验结果分别固定；单样本合法输出只能证明流程曾运行，不能证明推荐质量、成本优势或论文可比性。训练方法、Waterfall 本体、真人评分、消融、模拟用户和盲选不在本轮交付范围。

## 1. ClawRec-SimBench：共同环境只是受限代理

**数据原样包含什么。** 公开基准给出轨迹和可见网页线索，另有评测端的隐藏下一步行为；它没有发布可直接离线搜索的完整网页内容库。作者原流程依赖真实平台搜索。这里收集112个公开主题查询，冻结1,109条结果：B站556、知乎279、YouTube274，每条主要是标题、摘要、来源和链接，不保证包括正文。

**与原环境的差别。** 小红书、淘宝、京东、百度等不在这次内容库中。210个事件都至少有一个允许来源与内容库相交，只说明“有一个可用来源”，不能说明事件目标在库中、查询能找到相关内容，或所有来源同等覆盖。后续公开字段词项重叠审计虽覆盖210个事件，但中文单字重叠很宽松，不能当成目标覆盖率或相关性证据。查询主题是通用预设而非针对测试隐藏答案，但语料本身可能系统性偏向这些主题；共同库可以让各方法面对相同约束，不会消除主题覆盖偏差。不能把它当作作者原实验的全平台搜索成绩，也不能据此证明系统具备任意网站检索能力。

**时间限制。** 行为发生在2026年5–6月，快照在10月采集。虽然按照发布时间剔除晚于事件和发布时间未知的条目，但网页可能修改，当前标题或摘要不一定是行为当时版本。因此这是“事后采集、按发布时间过滤的受限快照”，并非严格历史回放。

**可见信息和旧测试。** 部分 `next_content_keys` 指向当前窗口外的内容；已删除这些链接并校验可见事件步骤。修复前四次连通测试及对应候选池不能用于比较；修复后两种方法各连续两轮真实运行，未读隐藏目标。该检查保证明确字段边界，不证明所有网页文本都不存在潜在时间线索。

**评测意味着什么。** 各方法输出先固定，再把输出去重合并成匿名内容池，由模型参照隐藏下一步行为逐条判相关性；共享池的理想排序用于 NDCG，Hit 使用论文阈值。它允许不同 URL 在语义上满足同一需求，但评价质量受裁判模型、提示和候选池影响。池内没有输出的内容不会进入相关性判断；模型判断与真人判断不能混成一张表。裁判完整链路已在一条冻结的真实事件上运行，两个 Agent 的匿名33条内容全部获得判断并完成指标计算；随后固定检索也在同一事件运行，三方法池共42条但尚未评分。这只是管线诊断，不作方法优劣结论，尚无正式全量评分。

## 2. AgentRecBench：Yelp 资料不完整，时间因果也受限

**缺失具体是什么。** 100条 Yelp 短历史官方任务中，74条至少有一个候选 ID 在官方物品资料中找不到，33条的用户 ID 在官方用户资料中找不到；两类重叠，共79条任务至少一处缺失，不能把74和33直接相加。ID 是真实的，缺的是与之对应的名称、属性或用户画像；部分缺用户画像的用户仍有真实评论。

**选择和影响。** 按用户决定，100条全部保留；缺失处只给真实 ID，不推测名称、类别、用户偏好或编造评论，并单列缺失统计。所有方法都应经过同样的可见信息适配，否则比较不公平。缺文本的候选很难做语义判断，会影响该领域的整体质量，尤其不同方法依赖资料程度不同；应同时报告缺失量和结果，不能把这一问题当作模型本身的特性。

**时间限制。** 已复用作者工具对目标用户—物品评论的遮蔽规则；任务公开字段没有明确的目标发生时刻，因此仅把可见评论按时间排序，不能证明每条评论都发生在目标前。当前可作作者工具约定下的离线评测，不能直接宣称严格时间因果验证。用户已允许 i²Agent 在 Yelp/Goodreads 按官方文件顺序处理，不能把该顺序称为时间顺序。100题中 i²Agent 分别有 Amazon 96、Yelp 32、Goodreads 92 条满足至少两条可见评论，其余 4、68、8 条为不适用；因此其分母与 RecAgent 全100题不同，比较时应额外报告相同适用子集，并保留全量任务状态。各领域各一个样本已跑通，不代表全量成功。

**原作者基线的适配。** RecAgent 实际实现将候选元数据加入列表的缩进存在问题；本地适配保留作者类和提示，仅修复该位置，让全部20个候选传入。输出必须是原候选的完整唯一排列，非法结果保留为失败。三领域各1条真实样本通过，不等于300条全量或真实评分通过。Baseline666 出现在论文结果中，但目前没有可核实的作者实现；用户已决定不纳入当前实验。

## 3. KuaiRec：观察掩码带来额外信息

**掩码是什么。** 用户—视频对有无观察记录来自 KuaiRec small matrix；运行时把没有记录的物品排除，保证后续指标只评价有观测的用户—视频对。掩码不直接包含观看比例或喜欢标签，但会告诉方法哪些物品在测试侧曾被观察。这是额外的测试侧可见信息，严格来说是“在可观测子集内推荐”，不是对完整互联网或不知哪些对会被观察的真实检索。

**公平比较。** ClawRec、通用 Agent 和 BM25+BGE-M3+BGE reranker 应使用同样的掩码、历史排除和100条获取上限。固定检索查询使用最近20条公开长观看文本；无查询使用训练侧冻结热度。实验需披露掩码来源、固定检索输入与检索参数。KuaiRec 的语义文本为后续静态补充，不能说2020年当时一定可用。

**当前验证范围。** 公开输入有开发282人、测试1,129人。三种方法已对相同两位用户完成真实流程或本地推理，结果合法且未读标签；全量执行和真实标签评分还没有跑。逐样本失败、进程中断和额度拦截要区分，不得把未运行的样本伪装成模型失败。静态任务每人一次，不能声称已验证跨期反馈和用户状态更新。

## 4. KuaiRand：样本、文本和时间窗口

原始数据量大，但目前按现有处理和时间协议冻结的任务只有36条：开发22、测试14。依照用户选择，各方法主要比较其中满足 i²Agent 两条正历史要求的35条，即开发21、测试14；另1条不可用单独报告。这是共同输入的可用条件，不是对全部原始用户的代表性保证；尤其14条测试样本不足以支持稳健显著性或大规模结论。

历史统一只暴露最近64条已完成行为，任务时刻和候选唯一性已做公开输入检查；不能根据目标或模型效果挑选样本。字幕补充文件是2026年公开的静态内容，无法证明2022年同样文本可用。已授权下载官方完整文件，完成后核验官方 MD5，再按视频 ID 和时长核验：时长无法核验时保留基础资料而不使用字幕，ID缺失或时长不符会阻止自动发布。当前下载与后续自动状态见 `kuairand/caption-finalization-status.json` 和 `kuairand/caption-live-check-status.json`，完成并核查前不可说 ready。

## 5. 方法实现及可归因范围

- **ClawRec**：SimBench 和 KuaiRec 使用作者公开的状态、计划和筛选技能，再对接本地共同搜索。MIND/KuaiRand 是给定候选的受限版，没有原系统的开放网页获取或语言纠正交互；名称需注明 adapted。
- **i²Agent / iAgent**：运行固定提交的作者五阶段类，并用可验证的候选排列替代依赖答案的重试。少于两条可用历史时不能构造其原流程，不补造历史；MIND 使用点击、KuaiRand 使用长观看，AgentRecBench 使用可见评论而不把每条评论都称为正向。作者仓库未发现许可证，本仓库只保存适配代码和固定哈希获取脚本，不分发作者源码。输入数据没有明确用户命令时留空，因此不能借此声称验证了指令遵循。
- **RecBot 语义变体**：自行实现论文公开的解析、偏好记忆、筛选与语义匹配；没有训练过的 AIA 协同模型和蒸馏组件。公开历史被用于语义匹配代理，不等于原 AIA；只能称 `semantic-only-no-trained-AIA`，不可声称完整复现或与论文分数等价。
- **MARS 自行复现版**：按论文设计三级记忆、更新与排序，但公开论文不包含所有作者提示和实现细节，分类和聚合存在明确自行选择；因此是论文复现版本而非作者原版。真实模型已在一条公开历史的三个事件批次上测试状态衔接，但两次更新计划均选择跳过，不能据此证明偏好发生真实更新；实际多会话与全量效果尚未验证。
- **通用 Agent 固定候选版**：先根据公开历史形成状态，再对候选排序；无开放搜索。若排列不完整，最多请模型纠正一次，重试和实际成本都保留；仍非法则记录失败，绝不自动补齐或伪造排序。
- **固定检索**：BM25 与 BGE-M3 通过 RRF 合并，再用 BGE reranker 排序。两模型使用既有权重，不训练；不同硬件的浮点结果可能有细微差异，资源账单需另记本地推理时间。

## 6. 对比、失败和费用

MIND 的主比较冻结967条满足 i²Agent 条件的共同输入，另报33条不可用；它只是原1000条诊断集合的子集，不是完整 MIND。数据没有显式用户指令，因此不能以它证明指令纠正能力。每个输入的标签与候选排序使用固定映射，必须先冻结各方法输出再读取标签；同用户多次出现时置信区间按用户聚类。

用户已决定不设各方法统一的模型调用次数上限，分别报告实际模型调用、token、耗时和可核实的成本；这表示方法能使用不同资源，结果应与资源并列解读。运行保护额度只是防止误触，不是对方法比较的共同预算。日志记录和合法输出不等于效益结果。

模型拒答、错误排列、空输出、网络故障、未运行和数据不适用属于不同状态。实际论文表需要提前写清各指标的失败处理与分母；不得只保留成功样本，也不得把预算中断或尚未运行算作模型失败。已有合成评分和少量真实模型测试只是管线验证；不得把旧 Waterfall 测试、不同输入或不同运行参数下的结果直接拼成一张公平对比表。
