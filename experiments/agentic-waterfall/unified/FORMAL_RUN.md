总计 75,690 项。输入、任务顺序、代码哈希、模型账本、结果及历次失败尝试保存在本机 `output/agentic-waterfall/waterfall-full-20261029/`，没有改写历史实验。入口为 `formal_queue.py --run-dir <运行目录>`；启动前用 `--max-new-tasks 30` 做交错验收。任务有完成结果则跳过，有开始标记却无完整结果则停下查账，不盲目重复付费。

`formal_task.mjs` 使用与 demo 相同的核心；适配层仅转换公开输入、内容获取接口和状态。当前核心 SHA-256 为 `89b38e7c0701ae770a8b2d5a6bd56f7b2078f2fba085c4322556ec62db46b36b`。工程验收补充了非法候选序号、JSON 截断的诊断反馈，由 Agent 在原 20 次模型调用预算内修正；不自动补排名。每次输出上限 8,192 tokens。初始行为窗口沿用 demo 的最近 60 条，原公开历史保留，可分页查询；这与旧单调用 MIND 协议不同，不合并为同一实验。

一个任务、一个模型请求、一个工具请求同时运行，nice 15，数值库线程 1，Node 堆上限 384 MiB；系统可用内存低于 20% 或磁盘低于 20 GiB 时等候。实验模型请求等待上限 180 秒，demo 默认保持 60 秒。运行依赖本机持续唤醒，休眠或重启不会自动维持进程。

仅对已完整落盘、没有有效提交且没有工具或格式错误的 HTTP 502/503/504、网络中断、请求超时做有限恢复：同一任务最多 3 次尝试，间隔 30/90 秒，重试前重新检查资源。被替代的服务失败保存到 `attempts/<任务>/service-attempt-NNN/`，每次调用均计入原总预算。持续失败、401/403/429、依赖跳过、未纠正输出错误、没有完整结果的中断立即停队；成功结果不重复运行或复制。

先冻结全部预测，`score_formal.py` 和 `score_formal_clawrec.py` 才在独立评价侧读取答案。错误不丢分母，不按测试效果换样本或调方法。评分产物有输入哈希和完成回执，未完成的付费判分不自动重试。

边界必须随结果报告：Yelp 79/100 任务存在公开元数据缺失，保留官方 null；ClawRec 使用 1,109 条固定公开快照，缺部分原来源，不是官方实时环境，单方法判分池不等于跨方法共享池；其判分与被测 Agent 使用同一模型服务。KuaiRec 有回溯性文本和观测集合侧信息；KuaiRand 遵循原始 64 条公开历史上限。此次运行不能单独证明完整论文实验或公平跨方法比较已经就绪。
