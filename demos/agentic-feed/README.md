# Waterfall · 个人信息流

独立的本机网页：本地人或 Agent 账号、兴趣与来源偏好、真实模型、多来源图文/视频、反馈、画像、Agent 模拟与数据导出。需要 Node.js 22；界面图标来自 Phosphor 和 Simple Icons。不修改 HarmonyOS 产品。

此前版本的检查见[验收记录](./verification.md)；该记录不代表本次改版已完成产品验收。

## 直接使用

```sh
cd demos/agentic-feed
npm ci
node server.mjs
```

打开 <http://127.0.0.1:4177>，输入用户名，选择人或 Agent。人可以填写兴趣和画像，也可以跳过；Agent 必须有画像，可以根据要求或随机生成并修改。

- **发现**：接近尾部前会预取；点赞、点踩、收藏、评论或多次较长停留会触发后台调整。也可随时在底部输入“电脑已经买好了，想学视频剪辑”。已看过的卡片保留；尚未看过的候选与新内容一起重新排序。卡片显示真实标题、封面、来源，点击到原平台阅读/观看。
- **我的画像**：一个文本框查看和修改画像及已有的手动记忆，单独显示交流中记住的事，并可修改兴趣。
- **内容来源**：选择从哪些可用来源获取内容。账号切换和数据导出在侧栏底部。
- **浏览轨迹**：按时间查看用户操作、Agent 输入与输出、工具调用和结果；连续的同类步骤会聚合在不同颜色的分组中，可以逐条展开，悬停或点击查看完整详情，也可切换账号下的历史会话。当前会话每 5 秒检查更新，Agent 账号可在轨迹页开始或暂停浏览。
- **研究数据**：在侧栏底部导出本次会话的 JSON；研究评价尚未加入界面。

用户名只用于区分本机账号，没有身份验证；知道用户名的人可以切换到该账号，包括已有的旧账号。退出后重新进入会恢复最近会话；旧数据保留。

## xuanji 配置

在原本机工作区中，启动默认只读原项目的统一私有配置，不复制密钥。其他环境请使用下方 `XUANJI_CONFIG_FILE` 或环境变量提供自己的配置；该私有文件不在仓库中。默认路径：

```text
HyperAgent/.worktrees/xuanji-device-latest-20261021/
  entry/src/main/resources/rawfile/hyperagent_config.local.json
```

模型选择优先级：`OPENAI_MODEL` → `recommendationModelName` → `modelName`。当前 xuanji 配置的推荐模型为 **DeepSeek-V4.1-Flash**；使用原版推荐链的关闭推理参数，包括 `extra_body.thinking.type=disabled`。`GLM-5.3` 是原版主聊天模型，并非这里默认的推荐模型。

```sh
# 使用另一份统一配置；模型、来源、Composio 配置一起读取。
XUANJI_CONFIG_FILE=/absolute/path/hyperagent_config.local.json node server.mjs

# 保留兼容入口。OPENAI_API_KEY / OPENAI_BASE_URL / OPENAI_MODEL 可覆盖模型字段。
MODEL_CONFIG_FILE=/absolute/path/hyperagent_config.local.json node server.mjs

# 明确选择规则演示，不调用模型。
DEMO_MODE=rules DATA_DIR=/tmp/waterfall-rules PORT=4179 node server.mjs

# 自动测试使用临时目录和模拟接口，不调用真实模型。
node --test
```

模型每阶段最多等 60 秒，一般一轮包含规划和排序两次调用；两个阶段分别使用合法动作 schema，排序列出本轮可选内容 ID。失败不会悄悄变成规则推荐。接口参数、请求模型名称、供应商返回名称、用量和失败阶段写入轨迹；不保存密钥或模型隐藏推理。

## 真实来源

来源接法按 xuanji 的实际工具工厂和供应商配置移植；接口选择限制在固定主机内。每轮由控制器按兴趣/指令挑选最多三个获取动作，不会把所有平台都查询一遍。

| 来源 | 已实现方式 |
| --- | --- |
| YouTube | 搜索；热榜接口保留，当前权限受限 |
| 哔哩哔哩 | 搜索视频 |
| X | 搜索；当前供应商额度耗尽 |
| Hacker News | 搜索讨论 |
| Reddit | 搜索帖子 |
| 知乎 | 搜索、热榜 |
| Apple Podcasts | 搜索播客节目卡片，跳转原平台 |
| Twitch | 搜索频道、发现直播 |
| GitHub | 搜索项目、发现项目 |
| Steam | 游戏新闻 |
| 中文资讯 | 原版四个公开 RSS 来源 |
| 国际资讯 | Guardian / NewsAPI 搜索和发现 |
| 维基百科 | 补充文字检索 |

逐来源实测、时间和限制见 [sources-status.md](./sources-status.md)。`configured` 表示凭据已配置，`status` 和 `mode_checks` 表示本进程实际请求的结果；两者不混为一谈。重启后的状态重新从“使用时检测”开始。网络、超时、429/5xx 等临时失败冷却五分钟后重新可选；402/403 继续显示外部限制。

文章可以附带封面，视频卡片跳转原站；没有伪装成本地视频/播客播放器。内容类型按来源真实能力约束，不提供尚无来源支持的纯图片推荐。语言设置影响检索与排序偏好，原文不会自动翻译。

## 控制器与个人状态

1. **规划**：联合当前指令、画像/记忆/情境、本人已记录的阅读行为，输出 `update_state`、0–3 个 `acquire`、`respond` 或 `keep`。
2. **获取**：从已启用的来源取得内容，保存实际返回摘要与元数据；获取结果再交给模型。
3. **排序**：只允许选择候选池中真实存在的 ID，最多六条；也可保持已有列表。显式重排可以复用候选池。

行动定义在 `core.mjs`，运行时校验来源能力、内容类型、状态版本、证据 ID 和候选 ID。模型不能引用尚未取得的内容。个人来源/内容设置同时作用于新检索和旧候选池。

画像和手工记忆保留在账号最近会话中；新建会话继承画像、长期记忆和 `persistent` 状态，清除会话情境及 `session` 状态。语言输入保留最近 8 条本人指令，行为输入最多最近 60 条本人信息流反馈/已结束曝光；不跨账号，也不读取盲测输入或选择。

## 研究采集与导出

侧栏“导出数据”生成 `awf-collection/1.0` JSON episode，以 [Agentic Waterfall 输入输出约定](../../docs/research/agentic-waterfall/02-输入输出与数据流.md) 和 [完整示例](../../docs/research/agentic-waterfall/materials/example/episode.json) 为对照：

- `metadata / initial_snapshot`：参与者类型、会话、初始画像与设置；真人和模拟数据分开标记。
- `decisions`：逐阶段保存真实输入快照、模型消息、原始与解析输出、校验、工具派发/返回、状态变化、耗时与用量；`canonical_input / normalized_output` 是对现有两阶段控制器的字段映射，保留原始值供核对。`source_records` 还保留这次会话的原始事件。
- `environment_snapshot / slates`：实际取得的来源内容、候选和排队列表；每个页面更新也记录实际添加、移除、可见和待展示卡片。内容仅含来源返回的摘要和元数据，并非完整网页或视频存档。
- `event_log / dialogue_log / feedback_windows`：指令、滚动、页面进出、曝光片段、打开/返回、赞踩、收藏、评论，以及内容、列表和曝光之间的引用。
- `simulator_decisions`：模拟用户的实际输入、输出或失败，不能当真人操作；`referenced_context` 保存实际输入引用到的同一账号历史。每个阶段完成就追加记录，中断时标记未完成。

卡片前台可见至少一半、持续一秒后记录曝光；用户更早点击时，以点击证明展示并立即开启曝光。跳转外站只记录打开和返回，不能测量外站的实际播放或阅读时间。尚未结束的曝光标记为 `open_or_interrupted`，不假定反馈或结束原因。历史记录缺少的字段保持空值，无法追溯的数据不会补造。

当前控制器仍运行既有的两阶段动作协议，并非声称模型原生输出了研究示例里的依赖图；映射动作 ID 由导出器生成并注明来源，实际输出、执行和不确定字段均保留。旧接口与原始 `agentic-feed-0.2.0` 事件日志仍保留；`format=jsonl` 可导出原始事件。默认 JSON 不加入盲测轨道，当前页面不做评测。

## 本机存储与边界

默认写入已忽略的 `data/`：`accounts.json` 保留旧账号的密码摘要、本机会话 token 摘要和个人设置；`events.jsonl` 追加阅读/研究事件。账号公开响应不含密码摘要或 token。文件权限 `0600`，目录 `0700`；会话 cookie 为 HttpOnly、SameSite=Strict，有效期 30 天。HTTP 接口逐项检查数据归属，旧匿名事件保留但不自动归给新账号。

服务只监听 `127.0.0.1`，同一数据目录只运行一个 Node 进程。当前没有公网部署、密码找回、删除账号界面、多人并发数据库或原生视频播放。损坏的日志会阻止启动以保护已有数据，修复前需保留副本。

默认真实模型会收到指令、相关状态、行为摘要和候选；账号凭据和来源密钥不在其中。Agent 模拟操作标记为 synthetic，不等同于真人行为。已完成的功能检查和真实接口冒烟只证明链路可运行，不代表推荐效果、人机偏好一致性或 ACL 实验结果。

## 当前实现边界

真实来源只提供平台返回的字段，不能补造未提供的正文、外站播放时长、真实依赖或结束原因。新采集包含队列状态和即时指令；旧会话只能导出当时已经记录的字段。当前 episode 用于采集与追溯，不等于研究效果验证。

新版保留用户已看见的卡片；重新排序只替换尚未看到的卡片。后台获取仍按批次执行，请求或来源失败时显示重试。B 站视频跳转原站，能否播放受来源和浏览器条件影响。
