# Waterfall：ACL 写作材料

下载日期：2026-10-20。

## 从哪里开始

- `official-template/acl_latex.tex`：ACL 官方 LaTeX 模板兼格式说明，可复制为写作入口。
- `official-template/acl_lualatex.tex`：官方 LuaLaTeX / XeLaTeX 入口。
- `official-template/acl.sty`、`acl_natbib.bst`：官方样式文件，保持原样。
- `acl-official-template.zip`：原始官方模板压缩包。
- `references/`：ClawRec、RecBot、MARS 的公开预印本，以及 iAgent 的 Findings ACL 2025 正式论文 PDF。
- `download-manifest.json`：来源、版本、文件大小和 SHA-256。

这些是模板与参考文献，没有代写或填入未经验证的 Waterfall 结果。RecBot、ClawRec、MARS 不应标注为 ACL 论文；iAgent 发表于 Findings ACL。

## 官方来源

- [ACL 2027 主会征稿](https://2027.aclweb.org/calls/main/)
- [ARR 投稿与模板要求](https://aclrollingreview.org/cfp#paper-submission-process-criteria-and-template)
- [ACL 官方样式仓库](https://github.com/acl-org/acl-style-files)
- 本地模板固定于官方提交 `d5adc823ff0f80f98c80405ca0ab66c68e684409`。

本次核对的 ACL 2027 长文正文上限为 8 页；投稿经 ARR，需使用匿名审稿格式。提交前再核对当轮要求。模板中的示例文字和参考文献是排版说明，不是 Waterfall 论文内容。
